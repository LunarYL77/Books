平台规则（边界）

  • 仅限教材教辅类书籍，其他商品会被举报下架
  • 仅支持校园线下面交，不支持邮寄
  • 平台不介入资金：钱款由买卖双方当面结清
  • 议价沟通在微信完成，平台展示卖家微信号
  • 交易纠纷由买卖双方自行协商承担

交易流程

  1. 卖家发布教材：实拍图 + 绑定课程 + 标价
  2. 买家按课程浏览 / 关键词检索，收藏或联系卖家
  3. 双方查看微信号，在微信上议价、约定面交地点
  4. 买家在平台提交订单登记，线下当面验书付款
  5. 买家回平台确认订单完成
