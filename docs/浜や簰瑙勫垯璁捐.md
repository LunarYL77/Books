# 大学生二手书交易平台 · 交互规则设计

> 参考原型：ZCode 主界面（会话侧栏 + 内容流 + 折叠卡片 + 结构化问答 + 计划审批 + 任务清单 + 通知系统）
> 版本：v1.0（2026-10-15） · 适用端：Web 桌面端为主，兼容移动端

---

## 0. ZCode → 本平台的模式映射总表

| ZCode 主界面模式 | 本平台对应 | 一句话规则 |
|---|---|---|
| 左侧会话列表 + 主内容流 | 左侧导航栏 + 书市内容流 | 固定左栏导航，主区只做一件事：流式浏览 |
| 工具调用折叠卡片（running/success/error） | 书籍卡片 / 订单卡片 | 默认折叠摘要，点击按需展开详情 |
| AskUserQuestion 结构化选项卡 | 发布书籍的分步引导 | 关键决策给 2–4 个带说明的选项，不做长表单 |
| 计划模式（先展示计划，批准后执行） | 下单前的"交易确认卡" | 交易动作先看清单，确认后才生效 |
| Todo 任务清单（pending/in_progress/completed） | 订单进度清单 | 多步流程可视化，当前步骤高亮 |
| 权限模式（自主级别可调） | 交易偏好设置 | 用户预设哪些动作需要确认 |
| 后台任务 + 完成通知 | 订单状态推送 | 后台到达不打断当前操作 |
| 斜杠命令 / @ 引用 | 搜索快捷语法 | `#分类` `@书名` `¥价格区间` |
| 骨架屏 / 空态 / 错误态 | 全局状态语法 | 三态规则全站统一 |

## 1. 设计原则（P 系列）

- **P1 渐进披露**：任何卡片默认只展示"封面 + 书名 + 价格 + 成色 + 状态"，其余信息折叠，点击展开。首屏信息密度优先。
- **P2 决策结构化**：所有关键决策（选分类、选交易方式、取消订单）用**带说明的选项卡**呈现（2–4 个），永远保留"自定义/其他"入口；不用开放式空表单。
- **P3 先确认后执行**：有后果的动作（下单、取消、确认收书）必须先展示**该动作将发生什么**（交易确认卡），用户点击确认按钮后才生效；确认后流程不再反复打断。
- **P4 状态始终可见**：每个异步操作有三个可见状态——进行中（骨架屏/转圈）、成功（轻量提示）、失败（原因 + 重试）。不允许"点了没反应"。
- **P5 进度可视化**：≥3 步的流程（发布、订单）渲染为清单式进度，已完成 ✓、当前步高亮 + 进行动画、未开始灰显。
- **P6 不阻塞前台**：消息、订单状态变化以后台通知送达，不打断用户当前浏览；用户正在填写表单时，任何弹层不得自动抢焦点。
- **P7 命令即入口**：搜索框是一级入口，支持快捷语法，熟练用户不依赖点选筛选器。
- **P8 反馈语法统一**：loading / empty / error / success 四态的样式、文案结构、时长全站一致（见 §9）。

## 2. 全局布局规则（L 系列）

- **L1 三栏结构**：左侧导航栏（固定 240px，可收起为 64px 图标条）｜中间内容流（自适应，最大 960px）｜右侧上下文面板（详情/预览，可收起）。
- **L2 内容流式加载**：书市列表滚动到底部自动加载下一页；加载中在流底部显示骨架卡片；无更多内容显示"已经到底啦"。
- **L3 响应式断点**：≥1024px 三栏；768–1023px 侧栏收为图标条、右面板变浮层；<768px 单栏 + 底部 Tab（书市 / 发布 / 消息 / 我的），发布按钮居中凸起。
- **L4 滚动位置记忆**：从详情返回列表时恢复滚动位置与筛选条件。
- **L5 全局搜索常驻**：顶部搜索框在所有页面固定可见，`/` 键随时聚焦。

## 3. 导航规则（N 系列，对应 ZCode 会话侧栏）

- **N1 侧栏分组**：
  - 书市：首页 · 分类浏览 · 求购广场
  - 交易：我的发布 · 我的订单 · 消息
  - 个人：收藏 · 足迹 · 交易偏好 · 设置
- **N2 主操作固定**：侧栏底部固定"发布二手书"主按钮（对应 ZCode 新建会话），任何页面一键可达。
- **N3 位置反馈**：当前页对应导航项高亮 + 左侧 3px 指示条；二级页面顶部显示面包屑（书市 / #考研 / 高等数学）。
- **N4 徽标规则**：未读消息显示数字角标（>99 显示 99+）；订单发生状态变化但非未读消息时，显示小红点；用户进入对应页面后清除。
- **N5 侧栏可折叠**：折叠状态记忆跨会话保留。

## 4. 书籍卡片规则（C 系列，对应 ZCode 工具调用卡片）

- **C1 默认态**：封面缩略图（4:3，无图显示书名占位卡）+ 书名 + 版次/作者 + 价格（加粗强调色）+ 成色标签 + 状态标记 + 发布相对时间。
- **C2 状态标记**：`在售`（绿）· `已预订`（黄）· `已售出`（灰，卡片降饱和但保留展示，供比价参考）。仅"在售"显示"联系卖家"主按钮。
- **C3 展开态**：点击卡片任意处展开（平滑过渡 ≤300ms），追加显示：详细描述、卖家信息（昵称 + 信用分 + 学生认证徽章）、交易方式（自取地点/快递）、留言板（最近 3 条）。再次点击或 `Esc` 收起。**同屏最多展开 1 张**，展开新卡自动收起旧卡。
- **C4 悬浮预览**：桌面端 hover ≥400ms 弹出快速预览浮层（大图 + 核心信息），鼠标移开即消失；触屏无此行为。
- **C5 卡片快捷操作**：右上角 `⋯` 菜单：收藏 · 分享 · 举报 · 屏蔽此卖家；星标收藏在 hover 时直接可见。
- **C6 已读反馈**：浏览过的卡片标题颜色变浅，与未读区分。

## 5. 搜索与筛选规则（S 系列，对应斜杠命令 / @ 引用）

- **S1 快捷语法**（搜索框占位文案提示）：
  - `关键词`：模糊匹配书名/作者/描述
  - `#考研`：限定分类（输入 `#` 弹出分类联想）
  - `@高等数学`：书名精确匹配
  - `¥10-30`：价格区间
  - 语法可组合：`#考研 ¥10-30 线代`
- **S2 即时联想**：输入防抖 300ms 后下拉联想（历史搜索 / 热门书名 / 分类），↑↓ 选择，Enter 执行。
- **S3 结果渐进加载**：结果页顶部 3 张骨架卡片，结果分页到达即替换；筛选条件变化时列表淡出重载。
- **S4 筛选芯片**：已生效筛选显示为可单独移除的芯片（chips），提供"清除全部"；`Esc` 清空搜索框。
- **S5 空结果兜底**：无结果时展示"求购广场"中相关求购帖 + "发布求购"按钮（搜索失败转化为需求）。

## 6. 发布流程规则（F 系列，对应 AskUserQuestion 引导式问答）

- **F1 分步引导**（共 5 步，顶部显示步进条）：
  1. 选分类：6–8 个带图标的分类选项卡（教材教辅 / 考研 / 考证 / 文学 / 工具书 / 其他）+ 自定义
  2. 书籍信息：支持 **ISBN 扫码/输入自动抓取**书名、作者、版次、封面；抓取失败降级为手动表单（仅书名必填）
  3. 上传图片：调用摄像头直拍，最多 6 张，拖拽排序，第 1 张为封面
  4. 定价：输入原价后显示**建议价参考**（同书近 30 天成交均价），成色与价格联动提示
  5. 交易方式：自取（选宿舍区/教学楼集合点）/ 送货到寝 / 快递，多选；可注明可议价
- **F2 选项卡规范**：每步的每个选项 = 标题 + 一行说明 + 可选缩略图；选中态有明确勾选标记；底部永远有"其他/手动填写"。
- **F3 可回退 + 草稿**：步骤间可点步进条回退修改；中途退出自动存草稿，下次进入侧栏"我的发布"可见并继续。
- **F4 预览确认**：最后一步是"买家视角预览"——渲染成真实书市卡片 + 交易确认卡，用户确认"发布"后进入书市（对应 ZCode 计划批准后才执行）。
- **F5 发布成功**：成功后显示结果卡片（含"分享到校园群"按钮 + "查看我的发布"），而非仅 toast。

## 7. 交易流程规则（T 系列，对应计划模式 + Todo 清单）

- **T1 交易确认卡（下单前）**：点击"我想买/预约"后弹出确认卡，**清单式列出**：书籍（缩略+书名）· 成交价 · 交易方式 · 时间地点建议 · 取消政策说明；主按钮"确认预约"，次按钮"和卖家商量"。确认后订单才创建。
- **T2 订单进度清单（Todo 式，五步）**：
  1. 卖家确认（待卖家响应）
  2. 双方约定时间地点
  3. 见面交易 / 发货
  4. 买家确认收书
  5. 双方评价
  已完成 ✓（绿色），当前步高亮 + 进行中动画，未来步灰显；每步右侧显示该步可用操作（如当前是第 2 步，显示"修改约定"）。
- **T3 状态实时同步**：任一方操作后，对方的消息会话中插入系统状态卡片（不可回复，仅展示），订单页清单同步刷新。
- **T4 确认分级**：
  - 普通操作（修改约定、留言）：直接执行
  - 关键操作（确认收书、完成评价）：确认卡二次确认
  - 破坏性操作（取消订单、退款申请）：红色按钮 + **后果说明**（如"取消后将通知卖家，该操作不可撤销"），需要点按"我已知晓"复选后按钮才可用
- **T5 超时规则**：卖家 24h 未确认 → 自动提醒一次；72h 未响应 → 订单自动关闭并通知双方；买家 48h 未确认收书且无申诉 → 视为完成。
- **T6 评价规则**：双方互评默认匿名展示；评分 1–5 星 + 标签快选（"书况相符" "守时" "沟通顺畅"，多选）+ 可选文字。

## 8. 消息与通知规则（M 系列，对应 ZCode 后台任务通知）

- **M1 会话结构**：每笔交易一个买卖会话流；订单状态变化以**系统卡片**形式插入会话时间线（含状态 + 时间 + 跳转订单按钮），不可回复。
- **M2 通知分级**：
  - 交易类（订单状态、超时提醒）：红点 + 角标 + 顶部横幅，强提醒
  - 互动类（留言、收藏、求购匹配）：红点，进页面清除
  - 系统类（公告、版本）：收进通知中心，不强提醒
- **M3 横幅规则**：顶部通知横幅 5s 自动收起，点击直达对应订单/会话；**同一时间最多 1 条**横幅，其余排队进通知中心；用户正在输入时（输入框聚焦）延迟到失焦后展示。
- **M4 免打扰**：交易偏好中可设置提醒时段（默认全天，可设 8:00–23:00）。

## 9. 全局状态与反馈语法（Fb 系列）

| 状态 | 规则 |
|---|---|
| 加载 >300ms | 显示骨架屏（卡片形骨架，非转圈）；>3s 追加文字进度 |
| 空态 | 插画 + 一句话说明 + **一个行动按钮**（"去发布第一本书" / "换个关键词试试"） |
| 错误 | 说明原因 + "重试"按钮；网络错误时**已填写的表单数据必须保留** |
| 成功（轻量） | toast 居中/底部 2s 自动消失（收藏、复制等） |
| 成功（重要） | 结果卡片 + 下一步引导（发布成功、订单完成） |
| 破坏性操作 | 红色主按钮 + 后果说明 + 不可逆操作需勾选确认 |

- **Fb1 操作防抖**：提交类按钮点击后立即置灰 + 转圈，防止重复提交。
- **Fb2 撤销优先**：能撤销的操作（收藏、下架）提供 5s 内"撤销"的 toast，而非弹确认框。

## 10. 权限与信任规则（Pr 系列，对应 ZCode 权限模式）

- **Pr1 交易偏好**（设置页，等价"权限模式"）：
  - 私信：所有人可私信 / 仅学生认证用户 / 仅我关注的人
  - 预约：需手动确认（默认）/ 信用分 ≥X 自动接受
  - 位置展示：精确 / 仅校区 / 隐藏
- **Pr2 信任标识**：信用分（0–100，含等级徽章）、学生认证 ✓、历史成交数，展示于卖家卡片与个人主页；未认证用户发布需先完成认证引导。
- **Pr3 举报与屏蔽**：任何卡片/会话内 2 次点击内可达举报入口；屏蔽后双方在书市互不可见。

## 11. 键盘与效率规则（K 系列）

- **K1** `/` 聚焦搜索；`Esc` 逐层关闭（先收起展开卡片 → 关弹层 → 清搜索）。
- **K2** 弹层内 `Tab` 顺序 = 视觉顺序，确认按钮支持 `Enter`，取消支持 `Esc`。
- **K3** 消息输入框 `Enter` 发送、`Shift+Enter` 换行（注明占位文案）。
- **K4** 列表页 `j/k` 上下移动焦点卡片（进阶，可选实现）。

## 12. 验收清单（示例）

- [ ] 任意书市卡片 ≤1 次点击可见全部关键信息（C1/C3）
- [ ] 发布流程无超过 1 屏的单页表单（F1/F2）
- [ ] 下单必须经过交易确认卡，确认后 5 步清单可见（T1/T2）
- [ ] 全站空态均有行动按钮；错误态均可重试且数据不丢（Fb）
- [ ] 通知不打断表单输入；同屏最多 1 条横幅（M3）
- [ ] `/` 键在任意页面可聚焦搜索（K1）
